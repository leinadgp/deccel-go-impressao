# Deccel Go Impressão

Programa para Windows que imprime sozinho os pedidos do Deccel Go numa impressora térmica ligada ao computador (USB).

**Baixar a versão mais nova:** https://github.com/leinadgp/deccel-go-impressao/releases/latest/download/Deccel-Go-Impressao-Setup.exe

- Funciona no Windows 10 e 11. Não precisa de senha de administrador do Windows.
- O Windows pode mostrar "O Windows protegeu o seu computador": clique em **Mais informações** e depois em **Executar assim mesmo**.
- Depois de instalar, entre com o usuário administrador da loja e escolha a impressora. O programa se atualiza sozinho.

Este repositório só guarda os instaladores. O sistema fica em outro lugar.
